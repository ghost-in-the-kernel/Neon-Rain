### J-081 The tree run lost to an idle container; the run made resumable, horizon by horizon
- **Who:** Claude Opus, a fresh Claude Sonnet agent (R-030).
- **Intent:** Run TODO 3.2 (b), the tree baseline, about 3.3 hours on the real data.
- **Found:** Opus started the run detached (`nohup`) with a background watcher, since a background task lives at
  most 2 hours. The run kept going while the watcher lived. At the watcher's 2-hour limit Opus replaced it with a
  scheduled check-in, which is not activity, and the idle container was reclaimed within minutes, `nohup` or not:
  the run died at horizon 21, fold 19 of 32, about 2 hours in, writing nothing (the trials file is unchanged).
  This container had already restarted several times this session. The agent made the run resumable:
  `neonrain/baselines/checkpoint.py` saves each finished horizon as a zip of JSON, parquet and raw float64 arrays
  (`allow_pickle=False`: a checkpoint is data, never code), named by the run's HAR-01 config hash and horizon
  and checked again inside the file, written atomically (a temp file, fsync, `os.replace`).
  `scripts/baseline_run.py tree` takes a checkpoint folder outside the repository and `--horizons`, and writes
  lines only once all four horizons are present. A resumed run writes lines byte-identical to an uninterrupted
  one (tested); the fixed-score baselines are unchanged. Gate: "precommit: passed; fast loop 29.89s, slow 48s,
  mutants 6397/6436 killed, the rest explained, 7.52 min". The hand-back opened with the canary.
- **Resolved:** The real run goes one horizon per background task (about 50 minutes each), so the session stays
  active and a cut costs one horizon at most. The config hash names no code version, so checkpoints are deleted
  after any change to the runner, the tree or the table's code (written in TODO 3.2). Lesson for long runs here:
  a live background task keeps a session's container; a scheduled check-in does not.
- **Touched:** neonrain/baselines/ (checkpoint.py, runner.py), scripts/baseline_run.py, test/test_checkpoint.py,
  test/test_baseline_run.py, docs/modules.json, docs/MUTATION.md, TODO.md, docs/NAVIGATION-LOG.md.
